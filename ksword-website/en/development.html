Versions and downloads

The download page provides complete packages, prereleases and CI builds. Use Launcher to choose the full application or Light. Available features depend on the installed version.

MCP and the command line

Use Settings → MCP to control the service, copy client configuration and view activity logs. MCP supports page navigation, native controls and KswordCLI. Mutating commands require confirmation. Installation instructions are in the MCP project.

Process details and permissions

Inspect threads, modules, handles, tokens and the PEB. Structured reports provide grouped browsing, search, field details and export. The permission workspace covers accounts, group membership, LSA assignments, token comparison and access diagnostics.

Registry workspace

Browse the registry in tabs, edit values or open registry documents. Preview changes before applying them and inspect the result afterwards. Common queries are also available in CLI and Light.

CKS management

The CKS page under Miscellaneous provides status queries, the official enrollment flow and an experimental SSDE flow. Its reset-free page contains research; reset-free enablement is not currently verified.

Memory inspection, editing and export

Hex, disassembly, text and difference views share a snapshot. Use x86/x64 assembly, staged edits, undo/redo and writeback. Region lists can export R3/R0 memory dumps. Choose from the access backends available on the current system.

API, ETW and syscall monitoring

Load the API agent for the target architecture to inspect parameters, return values and call stacks. ETW, syscall, WMI and callback monitoring provide session controls, filtering and export.

Files, disks and open handles

The dual-pane file manager includes metadata editing, hashes, signatures, string search and Hex views. Handle and mapping searches identify processes using a file. R0 file tools, raw disk and filesystem analysis are also available.

Drivers, callbacks and kernel objects

Browse drivers, device stacks, callbacks, SSDT, IDT and kernel objects. PDB/DynData support version-specific parsing, while the kernel knowledge center links reference topics to the relevant tools.

Intel and AMD virtualization

Intel VT-x / EPT provides resident monitoring and R-1 tools. AMD SVM / NPT and nested SVM are experimental. Check hardware detection and availability on the virtualization page before starting.

Nested virtualization

The topology demo shows how the host, guest and KSword relate in an Intel nested scenario. See the virtualization documentation for configuration, supported scenarios and test records.

R-1 memory tools

Read physical or virtual memory, translate addresses and locate target processes through an active virtualization backend. Write and target operations are enabled according to the capabilities shown in the UI.

Debuggers and clipboard protection

Cheat Engine and x64dbg run in their own windows and can use the KSword backend. Clipboard rules can log, allow or block access per process or globally, with agent connection status shown in the UI.

Light workspace

The native Win32 edition provides process inspection, detail navigation, snapshot comparisons and JSON/TSV export. It suits quick investigations and portable use, with a different interface and plugin scope from the full edition.

Windows, networking and navigation

Inspect Win32/UIA controls, manage windows and input order, or use connection, port and capture tools. The title-bar search locates pages; the Taskbar overview searches names and paths and opens the matching page.

Snapshots and export

Tables support filtering, copying, export and snapshot comparisons. Report search and copying use the complete document. Memory editors retain their read snapshots for before-and-after comparisons.

Start with inspection

Select an object and open its details. Common actions are above tables or in context menus; longer operations appear in the task center. Save the data you need before deletion, writes or driver changes.
