Versions & downloads

The Qt6 edition has the most features. Light uses native Win32, starts faster and avoids Qt6 compatibility limits. CLI handles scripts and batch operations; MCP connects AI clients to the GUI or CLI.

CLI / MCP

AI clients can read tables and controls, switch pages, perform actions and call KswordCLI. Use scripts for repeated queries and exports. Settings → MCP contains the service switch, client configuration and logs. Commands that change state require confirmation.

Process cross-view & structure details

Compare process lists, CID and thread sources to find objects missing from one view, orphaned threads and unusual entry points. Inspect modules, handles, tokens, the PEB and PDB field layouts. Permission tools also compare tokens, group membership and LSA rights.

Registry editing

Open multiple registry tabs, edit keys and values, or open registry documents. Preview the diff before applying changes and read back the result. Common queries are also available in CLI and Light.

CKS management

Check CKS status and use the official enrollment flow or the experimental SSDE flow. The reset-free page contains research notes; a working reset-free enrollment method has not been verified.

HVM / DMA cross-view & memory editing

Read the same memory through R3, R0, HVM private page tables and DDMA, then compare pages over multiple rounds. HVM avoids standard memory-management routines to check for read hooks. DDMA reads physical pages through the disk controller to check for EPT/SLAT redirection; it needs a configured channel and scratch sectors. The editor supports Hex, x86/x64 disassembly and assembly, staged edits, undo and diffs. Region lists can export R3/R0 dumps.

API, ETW & syscall tracing

API Monitor loads an agent matching the target process architecture and records arguments, return values and call stacks. ETW, syscall, WMI and kernel callback pages can filter records by target or event and export them.

File locks & disk analysis

File usage searches distinguish open handles from mappings and identify the owning process. Inspect metadata, hashes, signatures, strings and bytes. R0 file tools, raw disk access and filesystem analysis cover lower-level work.

Kernel callbacks, hooks & objects

Inspect drivers, device stacks, SSDT, IDT and kernel objects, and identify the modules owning callbacks and function pointers. Callback lists include process, thread, image, registry, Ob and Minifilter callbacks. PDB/DynData handles version-specific structures and offsets; kernel reference pages link directly to the relevant tools.

EPT, shadow pages & R-1

Intel VT-x / EPT supports separate original and execution views, shadow pages, hooks and execution breakpoints. Use the R-1 memory tools directly or connect CE / x64dbg. AMD SVM / NPT and nested SVM are still experimental; check hardware detection before starting.

Nested virtualization

The topology demo shows where the host, guest and KSword sit in an Intel nested setup. The virtualization docs list supported combinations, setup steps and tested configurations.

R-1 memory tools

With virtualization running, read physical or virtual memory, translate addresses and locate target processes. The page lists which read, write and target operations the active backend supports.

CE / x64dbg & clipboard protection

Keep using the CE or x64dbg interface while plugins connect it to KSword R0/R-1 memory and debugging, including EPT/Shadow execution breakpoints. Clipboard protection can log, allow or block access per process or globally.

Light edition

Native Win32, with no Qt6 dependency, fast startup and no Qt6 OS restrictions. Inspect process details, move between related processes, files, connections, handles and windows, compare snapshots and export JSON/TSV. Use the full edition for the widest UI and plugin support.

Windows, networking & page search

Inspect both Win32 and UIA control trees. Network tools show connections, port owners and packet captures. Find a page with title-bar search, or open it by name or path from the Taskbar overview.

Snapshot comparisons & export

Save table snapshots to see which rows and fields changed. Report search, copying and export include the full data. Memory editors retain read snapshots for byte-by-byte comparisons.
