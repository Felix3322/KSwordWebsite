2026-10-13 / UPDATE

Source updates

MAIN
  • MCP can inspect GUI controls and tables, switch pages and run actions. Added session settings, activity logs, startup/UAC options and CLI/IOCTL tools.
  • Memory regions can be dumped through R3 or R0. Process reports group fields and expand details inline; the PEB workspace is available again.
  • Added registry and object-permission operations. CLI and Light now share R3 query code; Taskbar can search pages and navigate through their hierarchy.
  • Parameter areas scroll independently and long tasks show progress. Reports are grouped for reading, while copy and export retain the full report.
  • Added CKS management and reset-free enrollment research. Reset-free enrollment is unverified; full L2 Windows validation on AMD is also incomplete.

2026-10-05 / UPDATE

Source updates

MAIN
  • The memory editor supports x86/x64 Intel assembly, staged edits, undo/redo and byte differences. Writes are checked by reading the target memory again.
  • API Monitor has 641 API definitions and separate x86/x64 agents. The main program can inject across bitness and show hook coverage and async I/O correlation. Fixed ETW process identity, event layouts and syscall records.
  • File tools gained metadata editing and backup, signature summaries, full-file string search and Hex navigation by offset. R0 deletion reports each stage separately.
  • EX callback removal rechecks the selected row and calls the matching public API. Minifilters are removed by unloading their owning filter. Added callback monitoring and 71 kernel topics.
  • CE/Titan debuggers share a backend, with EPT/Shadow execution selected by policy. Added clipboard-protection sessions, object navigation and investigation records in Light.
  • Added Intel nesting and page leases, plus experimental AMD SVM/NPT code. ENFORCE still returns UNIMPLEMENTED; running a complete L2 OS on AMD has not been validated.
  • Removed the upper OS-build gate and retained the minimum-version check. Individual features still check the current system and driver capabilities.

2026-08-27

KswordARK 5.1.4.3Pre

5.1.4.3Pre

Changes

  • Added the Kernel Knowledge center with 12 categories and 71 topics. Search the text, open official references, query live R3/R0 data or jump to the matching read-only page.
  • Added live monitoring for process, thread, image, registry, object and file callbacks, with filters, pause and drop counts. CLI gained matching query and start/stop commands.
  • Added Intel VT-x/EPT resident monitoring, with power, processor-topology and VMX-state checks. Driver unload is blocked during residency. This tag rejects AMD, an existing hypervisor or failed checks; later changes are listed in the development entries above.
  • Process details gained per-core CPU attribution, expandable charts, thread affinity, performance history snapshots and table comparisons. Startup entries support multi-select.
  • Light moved performance and bus tools to Hardware and grouped network and window tools under their own pages. Added process fields and details, switched to incremental refresh and fixed driver unload on exit.
  • Bugcheck diagnostics now group Stop Code, key processes and candidate modules. Installation is manual or configurable; ordinary driver loads no longer scan BGP private paths or register diagnostic callbacks by default.
  • Detail and report pages now group their fields. Title-bar search can filter by scope. Fixed combo-popup re-entrancy crashes and high-frequency refresh issues.
  • Fixed conflicts between SYSTEM/elevated restart and the single-instance check. Startup entries appear as they are enumerated. Removed the experimental storage-controller driver and UI from standard release packages.
