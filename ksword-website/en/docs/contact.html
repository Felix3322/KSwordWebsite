What to include in a report

  • The KSword Release or tag and complete patch identifier.
  • The Windows version and OS build.
  • Whether you are using the full edition or the Light edition.
  • Driver Loaded, Protocol, DynData, and Capability states.
  • The shortest reproduction sequence, logs, error codes, and necessary screenshots.
  • Remove private information, keys, tokens, real certificates, and sensitive paths before posting.
