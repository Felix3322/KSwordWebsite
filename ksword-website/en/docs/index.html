Choose a working mode

Start with R3 for basic process, file and network queries. Connect the R0 driver when kernel information is needed; each page shows its available functions.

Install and launch

Extract the complete package, keeping Qt dependencies, profiles, languages and plugin folders beside the application. Run Launcher.exe to choose an entry point.

Full documentation and limitations →

Connect the driver

Open driver management, select the matching driver and start it. Check the status and feature list after connecting. If loading fails, check administrator privileges, signing and system configuration.

Symbols and dynamic offsets

Use PDB/DynData profiles matching the current system modules. If a profile is missing, collect a report with Launcher and submit the compatibility information.

Connect a debugger

Install the matching Cheat Engine or x64dbg/x96dbg plugin, select a backend in KSword, then connect to the target from the debugger. The debugger keeps its own window; controls and logs remain in KSword.

Full documentation and limitations →

Inspect a process

Open process details and browse threads, modules, handles, tokens and memory. Confirm the process path and instance before acting. Common operations are in the context menu.

Edit memory and export regions

Read a snapshot, then choose Hex, disassembly or text. Edits are staged for review before writeback. Use the region context menu to export an R3/R0 dump. Partial reads fail; cancelled or failed exports remove the unfinished file.

Full documentation and limitations → Entries, save semantics and validation →

Files and handle searches

Browse files in the dual-pane manager. Use the context menu for properties, hashes or handle searches. Identify the owning process before choosing an unlock action.

Kernel tools

Connect the driver to inspect drivers, devices, callbacks and kernel objects. Use details, symbols and the knowledge center to interpret fields. Save current results before making changes.

Connections and ports

Find processes in the connection list and use port diagnostics to identify listeners. Capture tools provide interface selection, filtering and export. Confirm the target before changing connections or rate limits.

Install plugins

Install plugins from the plugin market or a local directory, reload them and open their page. Debugger plugins also require their host application.

Registry and system settings

The registry workspace supports value editing, document views and change previews. Check the result after applying changes. Keep the original configuration and backups before altering startup entries, services or raw disks.

Registry features and boundaries → Registry CLI commands →

End a session

Stop monitoring and debugging tasks before closing the workspace. Use the dedicated stop and unload controls for virtualization residency and driver operations.

Troubleshooting

Keep the error message, Windows version, application version and relevant logs. Check page status and dependencies, then report reproducible problems through GitHub Issues.

Start monitoring

Select a target and event types, then start an ETW, syscall or WinAPI session. Filter or pause the stream for inspection and export the records you need.

Virtualization tools

Check hardware and environment detection on the KVM page, then follow the prepare, start and stop sequence. AMD features remain experimental; see the virtualization documentation for configuration.

Use Light

Light provides native Win32 inspection, entity navigation and snapshot comparison. Export query results as JSON/TSV. Its feature and plugin scope differs from the full edition.

Clipboard protection

Configure read, write and enumeration rules per process or globally. Start protection, check agent status and logs, then adjust allow, log or block policies.

System requirements

The full edition requires Windows 10 1809 (build 17763) or later on x64. R0 features additionally depend on driver signing, system configuration and dynamic offset support.

Full documentation and limitations →

Connect MCP

Open Settings → MCP and copy the installation prompt or client configuration. Choose GUI, CLI or both and set the startup behavior. Administrator startup uses a Windows UAC prompt.

MCP tools and configuration → Installation and validation →

Use the command line

Run KswordCLI help for commands, or browse process, file and registry references in the documentation center. MCP can invoke CLI tools. Raw IOCTL requests require explicit confirmation and are limited to 1 MiB per input and output.

CLI reference → R3 coverage manifest → IOCTL syntax and limits →

Reports and permissions

Expand structured reports in process details, search fields and copy or export the document. The permission workspace inspects accounts, groups and tokens, compares snapshots and diagnoses access permissions.

Report behavior and validation → Permission workbench →

Find a page

Search pages and controls from the title bar, or open the overview with the grid button on Taskbar. Enter a name or path and press Enter to navigate; Esc closes the overview.
