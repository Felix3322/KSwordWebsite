Which program to use

Use the Qt6 edition for the full set of pages and plugins. Light uses native Win32 for a quick start and systems outside Qt6’s supported range. Use KswordCLI in scripts. Basic queries work without loading a driver; kernel enumeration, R0 memory and HVM require their respective backends.

Install and launch

Extract the complete Release/ folder and run Launcher.exe to choose the Qt6 edition or Light. Keep the Qt DLLs, platforms/qwindows.dll, profiles/ and languages/ beside the application. For missing-DLL or Qt platform plugin errors, check for an EXE copied on its own or dependencies mixed between packages.

Connect the driver

Load KswordARK.sys from the same release in driver management. Loaded reports driver loading; Protocol reports communication compatibility; DynData reports private-structure offsets for this system; Capability lists the functions available now. If one page fails while the driver is loaded, read that function’s diagnostic.

Symbols and dynamic offsets

A Windows update can leave some kernel functions without matching offsets. PDB/DynData profiles match exact system-module identities; a nearby build is not a substitute. If Launcher reports a missing profile, follow its report collection flow. --launcher-check-only checks the support manifest without creating a report.

Connect a debugger

Install the matching Cheat Engine or x64dbg/x96dbg plugin, choose a backend on KSword’s debugger page, then launch the debugger and attach to the process. For R0/HVM modes, check the log for the mechanism actually selected, including any native fallback. The debugger has its own window; KSword holds the backend options and logs.

Inspect a process

Double-click a process for thread start addresses, module signatures, handles, memory regions, tokens and PEB data. To investigate a missing or hidden process, cross-view the available R3/R0, HVM or DDMA sources and see which layer reports it. Match PID and creation time so process exit or PID reuse does not look like hiding.

Edit memory and export regions

Attach to a process, select a read backend, address and length, then inspect the same bytes as Hex, disassembly, text or a diff. The region context menu exports an R3/R0 region dump as raw .bin bytes, sized to that region rather than a whole-process minidump. Short reads and cancellation do not publish an unfinished file. Live memory can still change between read chunks.

Files and handle searches

Browse directories in two panes and open file details for PE headers, sections, signatures, hashes and strings. For a file-in-use error, inspect the owning processes, handles and module mappings. A mapped DLL is not the same as an open file handle: a mapping entry may have no file handle you can close.

Kernel tools

Under Kernel → Object namespace, follow directories to inspect objects, symbolic links and target paths. Atom tables can also be queried directly. SSDT and kernel callback pages need the matching R0 capabilities. The callback list shows registrations and owning modules; Callback Monitor shows events after its session starts. Use the kernel knowledge center for field definitions.

Connections and ports

For a port conflict, check the PID, local address and port in the connection list, then open the process. UDP entries do not have TCP connection states. Packet capture selects an interface and filters; manual requests expose URL, Header, Body and the response. HTTPS analysis uses a local proxy with certificate and system-proxy changes; restore those through its controls when finished.

Install plugins

Install through the plugin market or load a local directory, reload, then open the plugin’s page. CE and x64dbg/x96dbg adapters also need the debugger itself and files for the matching architecture. A plugin download does not install its host application.

Registry and system settings

Edit registry keys and values in the tree, or use the document view to preview changes. If a known key appears missing, check the 32/64-bit registry view. Startup entries bring files, registry values, services, scheduled tasks and WMI entries into one list with links to their sources. Disabling and permanently deleting an entry have different recovery behavior; read the selected action’s prompt.

End a session

Stop each monitoring session with its own controls. Stop HVM residency on the virtualization page before unloading its driver. Closing a page or the main window does not necessarily unload the global driver service; check driver management and the reported HVM state.

Troubleshooting

Keep the complete startup error. For an unavailable function, include its diagnostic and driver capability state. A useful bug report gives the package used, Windows build, CPU and virtualization environment, the first failing step and the original error code. A short reproduction sequence is easier to investigate than “it does not work.”

Start monitoring

Choose ETW, syscall or WinAPI monitoring, then select the process and event types. Check session readiness, Hook coverage and lost-event counts before interpreting the table. An empty stream can come from filters, a bitness mismatch or injection status. API Monitor and clipboard protection cannot hold a session on the same process at once.

Virtualization tools

On the Virtualization page, check CPU capabilities and rejection reasons, then prepare, self-test and start residency. Check the full expected CPU set rather than a checked switch. Intel uses VMX/EPT; AMD uses the experimental SVM/NPT backend. A complete multicore inner OS on AMD has not passed final validation; use the current capabilities and experiment records to check a particular feature.

Use Light

Light starts without Qt6 and suits older systems and quick queries. Enter pid, tid, hwnd, file or reg in its command box to navigate to an object; a leading ! executes a command. Export results as JSON/TSV or compare the last two snapshots. Use the Qt6 edition for its full pages and plugins.

Clipboard protection

Under Miscellaneous → Clipboard protection, set read, write and enumeration rules per process or globally, choosing allow, log or block. The Agent Hook inside the target process enforces the rules. Check agent readiness and matching log entries after starting; a driver policy table alone does not mean every access is intercepted.

System requirements

The Qt6 edition requires Windows 10 1809 (build 17763) x64 or later. Launcher can select Light on earlier Windows 10 builds. The driver has a separate minimum of build 16299, so launching Light does not establish R0 support. Private-structure functions on newer systems also need matching DynData.

Connect MCP

Enable the object bridge under Settings → MCP, then copy the installation prompt or client configuration. CLI-only use does not require a running GUI. GUI mode can connect to an existing instance or use explicitly configured automatic startup. Matching the full program path avoids updating a fixed PID after every restart. Verify the connection with GUI hello/pages/snapshot or CLI status/help.

Use the command line

Run KswordCLI help for commands and parameters, then use the process, file or registry reference as needed. Scripts and MCP can call CLI without opening the GUI. Raw IOCTL is a separate low-level entry requiring explicit confirmation, with 1 MiB limits on input and output. Use the existing commands for routine queries.

Reports and permissions

Structured reports in process details expose types, offsets and field values. Search, copy and export use the same document. A PDB field catalog describes layout; live values depend on successful collection. The permission workspace inspects accounts, groups, tokens and access rights, with snapshot comparison to find what changed.

Reading structured reports → Permission workbench →

Find a page

Use title-bar search for a page name, path or control label; select a result to navigate and highlight it. The grid button on Taskbar opens the page overview: type a name or path, press Enter to navigate or Esc to close. Commands run only after switching the title bar to CMD mode.

CKS management

Miscellaneous → CKS management shows current status and enrollment flows. Its third subpage contains reset-free research, not a working reset-free method. Neither startup re-enrollment nor repair installation has been verified. Read the recorded system builds and evidence for the exact limits.
