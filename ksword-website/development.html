版本与下载

下载页面提供完整安装包、预发行版和 CI 构建。使用 Launcher 选择完整版或 Light，具体功能以所安装版本为准。

下载文档MCP

MCP 与命令行

在“设置 → MCP”启停服务、复制客户端配置并查看操作日志。MCP 支持页面导航、控件读取与操作，也可调用 KswordCLI；执行修改命令时需要确认。安装说明见独立 MCP 项目。

进程详情与权限

查看线程、模块、句柄、令牌与 PEB。结构化报告提供分组浏览、搜索、字段详情和完整导出；权限工作台集中账号、组成员、LSA 分配、令牌比较与访问诊断。

注册表工作台

按标签页浏览注册表，编辑键值或打开注册表文档。修改前查看计划和差异，应用后读取结果；常用查询也可通过 CLI 与 Light 完成。

CKS 管理

杂项中的 CKS 页面提供状态查询、官方登记流程和 SSDE 实验流程。免重置页面整理研究资料，目前没有经过验证的免重置启用方案。

内存查看、编辑与导出

Hex、反汇编、文本和差异视图共用快照。支持 x86/x64 汇编、暂存编辑、撤销/重做和写回；区域列表可导出 R3/R0 内存 dump。读取与写入后端按当前机器的可用能力选择。

API、ETW 与 Syscall

按目标位数加载 API Agent，查看调用参数、返回值和调用栈。ETW、Syscall、WMI 与回调监控提供会话管理、过滤和导出。

文件、磁盘与占用

双面板文件管理器集成属性编辑、哈希、签名、字符串搜索和 Hex 浏览。占用查询按句柄或映射定位相关进程；另有 R0 文件工具、原始磁盘与文件系统分析。

驱动、回调与内核对象

浏览驱动、设备栈、回调、SSDT、IDT 与内核对象。PDB/DynData 提供版本相关解析，内核知识中心连接专题说明和对应工具页。

Intel 与 AMD 虚拟化

Intel VT-x / EPT 提供常驻监控与 R-1 工具。AMD SVM / NPT 和嵌套 SVM 为实验功能；启动前查看页面中的硬件检测和当前可用状态。

嵌套虚拟化

拓扑演示展示 Intel 嵌套场景中主机、虚拟机和 KSword 的位置变化。实际配置、支持进度和测试记录可在虚拟化文档中查看。

R-1 内存工具

提供物理/虚拟内存读取、地址翻译和目标进程定位；需要已启动的虚拟化后端。写入和目标操作按页面显示的能力启用。

调试器与剪贴板保护

Cheat Engine 与 x64dbg 使用独立窗口，可连接 KSword 后端。剪贴板保护按进程或全局规则记录、允许或阻止访问，状态显示当前 Agent 的连接情况。

Light 轻量工作台

原生 Win32 界面提供进程查询、详情导航、快照比较和 JSON/TSV 导出。适合快速调查与便携使用，界面和插件范围与完整版不同。

窗口、网络与页面导航

检查 Win32/UIA 控件、管理窗口和输入顺序，或使用连接、端口与抓包工具。标题栏搜索可定位页面；Taskbar 总览支持按名称和路径搜索并直接跳转。

快照与导出

表格支持筛选、复制、导出和快照比较。报告搜索与复制使用完整文档，内存编辑器保存自己的读取快照，便于保留操作前后的数据。

从查询开始

先选择对象，再打开对应详情。常用动作位于表格上方或右键菜单，耗时任务可在任务中心查看进度。涉及删除、写入或驱动修改时，先保存需要的数据。
