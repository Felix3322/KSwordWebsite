02 / SYSTEM TIME

系统级时间加速、减速与校准时钟

Miscellaneous 页新增系统时间控制链路，可在驱动侧调整系统性能计数器的时间推进速度，并提供兼容模式与带额外校验的安全模式。安全模式只能降低一部分错误配置风险，仍可能导致冻结或蓝屏。

控制与恢复
  • 系统级加速或减速
  • 倍率与模式选择
  • 双重风险确认
  • 停止变速并恢复原始计数器
时间显示与同步
  • 调用 Windows Time 执行重新同步
  • 15 秒响应超时与错误诊断
  • 按当前倍率计算校准后时间
  • 标题栏显示系统时间和 KSword 运行时长
这不是应用内的“动画倍速”。

该功能影响整个系统对时间的观察。网络协议、许可证、定时任务、日志顺序、反作弊、数据库和其他依赖单调时钟的程序都可能出现异常；必须先准备恢复路径。

对应提交：ab93b7e、5933bda、8a4bd0d、a7127b3、2260e06。

03 / NETWORK

R0 网络审计进入 WFP 报文层

网络页不再只展示连接、端点或 WFP 事件。新协议可以从驱动侧增量读取 WFP IPv4/IPv6 IP packet 层捕获结果，并在用户态严格验证响应头、行大小、序列号、地址族、TCP/UDP 协议、报文边界和有限捕获长度。

逐包增量读取

客户端通过 afterSequence 游标继续获取新包，避免每次复制完整历史。

丢包与游标诊断

响应会区分截断、游标缺口、游标重置、驱动侧丢包和 WFP 不可用。

协议兼容判断

旧驱动缺少新 IOCTL 时会明确标为 Unsupported；不能把空表误判为“系统没有流量”。

配套 R0 视图

继续整合 TCP、UDP、AFD、NSI、NDIS 与 WFP inventory/cross-view，便于把逐包证据与内核对象视图关联。

这一页最依赖客户端与驱动同版。

新增 packet ABI、NDIS 依赖和诊断文本在连续提交中补齐。混用旧 SYS 和新 EXE 会直接触发 Unsupported、协议验证失败或字段缺失。

对应提交：eabec0d、bcb8386、f8710df、5a46b70。

04 / FORENSICS

结构化扫描、内核基线、原始文件系统与受控 HVM

Scanner Dock

后台解析 PE、ELF 与 Mach-O。可选字节编辑器只允许等长修改，写回前重新验证源快照，采用原子替换，并可保留备份。

高级内核取证

增加已加载映像与 IDT 干净基线、描述符表和 IOCTL 解码、内核反汇编、系统线程与工作队列视图，以及更完整的回调和对象审计。

存储取证

新增默认只读的原始文件系统浏览，可检查目录项、删除记录和底层存储证据；磁盘写入仍需单独解锁与确认。

HVM 诊断

提供确认门控的 VMX 自检和一次性测试 guest，并输出 VM-exit telemetry；定位是授权实验室诊断，不是通用虚拟机。

这些能力与原有 DriverObject、DeviceObject、SSDT、Hook、回调、模块 Cross-view、Unloaded/PiDDB、PTE 和内存证据形成同一条取证链路。

对应提交：8ce2b2a、7ba04ed、21cc83f、7ff3ee8。

05 / RUNTIME

运行时 PDB 回退、长期运行诊断与界面控制

  • 随包 DynData profile 不匹配时，完整版本与 Light 版本可在串行 DbgHelp 会话中解析精确运行时 PDB；只有 PE/PDB 身份验证成功的结果才会被应用。
  • 表格新增冻结控制和平滑滚动，避免大表刷新时误选或丢失当前检查位置。
  • Core Audio 声音来源检查扩展，便于把正在输出声音的会话关联到进程与设备。
  • API Monitor Agent 改为可等待下一次会话、识别新 session ID，并能中断挂起的管道写入，减少停止后无法重启和退出期崩溃。
  • 磁盘性能监控、异步视图快照与驱动搜索继续修正生命周期和竞态；Release 构建也补齐 Qt runtime 部署。
运行时 PDB 是精确回退，不是“相近版本偏移猜测”。

身份不匹配或字段不完整时，依赖该字段的 R0 能力应继续安全降级，而不是跨 Windows build 套用偏移。

对应提交：6943a1a、4d7eb6a、44b21d0、a323cb0。

06 / HARDENING

危险操作确认与审计边界继续收紧

进程终止

结束进程树、关键目标等破坏性终止动作增加明确确认，降低一次误点影响多个目标的概率。

启动项与永久删除

执行前重新验证当前目标；机器级启动项停放、注册表恢复记录和删除动作强化访问控制与恢复事务。

进程与线程身份

历史进程记录、线程动作、工作队列审计和异步菜单刷新改为使用更稳定的身份快照，并修复退出/刷新期间的生命周期竞态。

平台与内核基线

加载映像、平台安全、目录服务、回调与硬件审计增加边界验证，避免把不可信内核数据直接当作可遍历对象。

代表提交：c02d2e0、8be550b、82e6264、cfca4cc、7ef8370。

08 / OPERATOR NOTES

在 main 上测试前必须知道的事

  1. 1
    整套构建必须来自同一提交。

    尤其是主程序、KswordARK.sys、共享 IOCTL 头、语言包和 DynData profiles。

  2. 2
    先验证 Driver Status 和 Capability。

    按钮可见不代表目标 IOCTL、PDB 字段或内核能力已就绪。

  3. 3
    系统时间、HVM、磁盘写入和内核修改只在授权环境中测试。

    准备虚拟机快照、恢复介质或至少一条可验证的回滚路径。

  4. 4
    要稳定资产就使用 Releases。

    本页不会把 main 的开发状态伪装成一个不存在的正式版本号。
