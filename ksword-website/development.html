02 / KERNEL & R0

内核审计、动态偏移与故障闭合

新增或增强审计
  • IDT、代码完整性、VBS/HVCI 姿态、页保护。
  • SLAT/IOMMU、EPT/NPT、Hypervisor CPUID、DMAR/IVRS。
  • HAL、WDF/KMDF、i8042prt、对象类型、特殊回调和 IoTimer。
  • 系统线程、工作队列、描述符表、IOCTL 解码与内核反汇编。
运行时安全
  • PDB 无关的运行时签名扫描与偏移回退。
  • DynData v4 profile 与 Launcher 支持清单。
  • 安全读取回退内核地址，降低 DriverEntry 阶段蓝屏风险。
  • 物理机 BugCheck 面板故障闭合，并保留 VMware 显示路径。

这些页面仍然受 Driver Status、Capability、DynData 和目标身份门禁约束；按钮可见不代表对应 R0 能力已就绪。

03 / DUMP FORENSICS

崩溃转储从结构展示扩展到归因证据

近期开启独立转储分析工作流：加入 triage 崩溃上下文、triage 数据块、二级转储记录、捕获内存和 BlackBox 证据预览，并结合符号解析、Pool Tag 归属和崩溃时间线给出更完整的诊断材料。BugCheck 相关显示在物理机和 VMware 路径之间保留明确边界。

转储内容是诊断证据，不是自动归因的绝对结论。

页面展示的缺失字段、Unsupported 和部分记录必须保留，不能用默认值填成“正常”。

04 / PROCESS & SECURITY

进程身份、启动链与攻击链检测

进程与线程

进程表补齐接近任务管理器的列，支持自选列、自定义视图、目标线程消息钩子、线程/模块/令牌/PEB 详情，以及基于对象管理器回调的可续期进程保护。

启动与加载

新增 DLL 劫持候选检测、IFEO 镜像劫持检测、隐藏启动项交叉比对和 EXIT GhostSystemDriver 攻击链检测；启动位置目录扩展到 187 条。

应用控制

补齐 AppLocker 模块加载容错、应用控制编辑器和上下文动作。全局热键支持安全编辑与删除，服务枚举和清理流程也继续加固。

文件与存储

06 / LIGHT

KswordARKLight 接入更多只读页和可逆控制

Light 版本新增网络、窗口、系统工具、性能总线、服务、权限等模块，并接入逐包捕获控制、PiDDB 条目删除、物理磁盘读取，以及驱动派遣/镜像/通信的恢复或放弃动作。涉及写入、删除、恢复或放弃记录的动作继续使用显式确认、代次校验和结果回填。

“放弃”不改内核状态，但会永久丢失恢复记录。

因此放弃动作比恢复动作更危险，网站和程序文案都应保持这个区分。

大表格、任务栏和主题体验继续调整

主线加入自适应表格搜索范围、表头排序、冻结行列、任务栏通知筛选、目标线程消息钩子展示、蓝屏面板调整、动态主题和透明背景修复；同时继续收敛文件占用扫描、异步刷新、驱动搜索、API Monitor、硬件监控和退出阶段的生命周期问题。

这些提交中有相当部分是稳定性修复或内部实验，不应被包装成单独的正式功能版本。

09 / OPERATOR NOTES

在 main 上测试前的最低检查

  1. 1
    整套构建必须来自同一提交。

    不要只替换 EXE、SYS、语言包、profiles 或插件。

  2. 2
    先看 Driver Status、DynData 和 Capability。

    Unsupported 表示协议、驱动或能力不匹配，不等于页面没有数据。

  3. 3
    高风险动作只在授权和可回滚环境测试。

    系统时间、HVM、磁盘写入、驱动卸载、内核修改、进程保护和删除动作都应准备快照或恢复路径。

  4. 4
    保留修改前证据。

    导出目标身份、地址、来源模块、配置和时间戳；动作后刷新并保存新旧结果。
