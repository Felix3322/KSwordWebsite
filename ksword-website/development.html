01 / SCOPE

源码与发行边界

02 / MEMORY

统一内存编辑器与 Intel 汇编

主程序的 R3/R0/R-1、DDMA、影子页、Hook 向导、内核反汇编与转储内存入口共用快照组件。Hex、文本、反汇编和对比使用同一份字节；橙色表示待提交修改，青色表示两次读取的变化，提供本地撤销/重做。

x86/x64 Intel 汇编支持多行、局部标签、实际地址分支与 RIP 相对寻址。数字默认十六进制，十进制用 0d；编译和预览仅暂存字节，所属页面显式应用，写前核对原字节、写后检查实际回读。它不实现 CE Auto Assembler 脚本。只读入口不会因可查看汇编而获得写权限。

03 / MONITORING

API、ETW、Syscall 与回调监控

API Monitor 已有独立 x86/x64 Agent、641 项共享 JSON 定义、主程序集中跨位数注入与子进程会话服务。API 覆盖页展示实际安装、等待、排除与失败；异步 I/O 区分提交、完成和取消。Raw 只记录入口，直接 syscall、任意 COM 和监控前调用不保证覆盖；TSV 只导出当前可见行，队列丢失单独计数。

ETW 按载荷关联进程与线程，保留原始事件头身份；数组、结构和 TraceLogging schema 按布局解析，未知或截断留证据缺口。Syscall 以原始 QPC、CPU 和 StackWalk 关联，兼容桩形态仅作为证据，不能由单个 syscall 字节或 RWX 判定恶意/工具版本。

内核回调监控使用独立 Control/Query/Read 与多消费者游标；暂停冻结 UI 提交，后台继续有界读取。它观察 Ksword 运行时回调事件，区别于列出系统注册回调和 AskUser 拦截规则。

04 / FILES

文件详情与 R0 删除

文件详情提供单文件/批量元数据暂存，底部“保存全部修改”统一复核文件身份、备份、写入与回读。基础时间/属性、ADS、EA、权限、重解析点、文件系统属性和 PE 资源各有边界；高风险修改强制备份。签名页突出 WinVerifyTrust 信任结果，字符串按条件扫描全文件，Hex 支持按偏移分页跳转。

R0 删除有分阶段回执。IRP 预设采用托管打开并向基础文件系统提交，普通/忽略共享/强制方式保留不同风险与确认；强制清空映像/缓存 section 成员不能保证活动映射一致性。关闭句柄后确认路径不存在才算完成，构建或模拟测试不能证明实机删除安全。

05 / KERNEL

回调注销与内核知识中心

V3 回调清单保留注册变体、来源、身份与可信状态。Object 使用真实 RegistrationHandle，Registry 使用 Cookie；EX 请求在驱动重新枚举核对，公开 API 调用后复核目标。新增配对注销类别保留 candidate，不宣称所有版本已验证；实验 unlink 菜单已移除，ETW/EMP 缺真实句柄的行仍不可移除。

Minifilter 子行的动作是“卸载所属过滤器”，包括全部回调和实例，过滤器可拒绝。知识中心提供 12 类 71 专题、现场证据与只读业务页路由；Available 表示链路闭环，不证明当前机器全部权限/偏移/字段可用。

06 / VIRTUALIZATION

Intel EPT 与 AMD SVM/NPT

当前代码包括 Intel 常驻、MSR bitmap、退出模拟、EPT 双视图/策略，以及 AMD SVM/NPT 实验后端。标题栏与 KVM Dock 共用准入，按硬件、逐 CPU 自检、电源代次、拓扑和卸载保护发布状态；未知外层与 Hyper-V/VBS 冲突不能靠开关绕过。

EPT ENFORCE 当前返回 UNIMPLEMENTED。

不能将旧 #PF 拒绝路径宣传为已完成的持久强制。WATCH_ONCE 捕获首次访问现场后放开对应页，不是所有后续写入的日志。代码执行分离视图不是普通数据冻结或通用进程隔离。

07 / NESTED

嵌套实现与验收范围

Intel 已有 vmcs12、退出反射、影子 EPT 及后代页/区域租约；支持、准备、全核 armed 和瞬时 L2 运行分别报告。AMD 已有通用 VMCB/NPT、事件协调与首故障记录，但保持实验 PARTIAL。

已保存 AMD 单核/8 核启停和 32 核短常驻证据。固定探针逐核串行往返不等于内层多核 OS 并发；完整 L2 启动已有三重故障/宿主崩溃记录与待复测候选，不能宣布完整 OS 兼容。七步拓扑演示保留的是历史 Intel/Hyper-V 示例，不覆盖 AMD 或所有外层配置。

08 / R-1

R-1 内存与目标操作

R-1 内存支持物理/虚拟读写、翻译与按 PID 定位。私有窗口不可用时读取可降级并明确报告，写不可用；快照绑定地址、CR3/PID、模式与代次。目标操作还需要正确目标身份、映射、策略与常驻状态。所有界面应检查具体回执，不能把请求成功当作目标已退出或字节已改变。

09 / DEBUGGERS

CE / x64dbg 与剪贴板保护

共享调试后端管理身份、内存、上下文、HVM 与自有资源；CE/Titan 使用真实 Windows 停止事件。执行断点可按能力走 EPT 或明确记录的 Shadow INT3 回退。隐蔽模式拒绝可见 DR/PAGE_GUARD 回退；CE 与 Titan 的数据断点范围分别维护。Shadow 代码写入要求私有/COW 页，不能等同数据 freeze。

剪贴板保护按位数选 Agent，与 API Monitor 共享 PID 租约，配置可热更新。仅收到 Hook 安装就绪才计入受保护进程；规则命中/注入成功不等于全局保护，跨用户、直接调用和受保护目标保留覆盖限制。

10 / LIGHT

Light 调查工作台

原生 Win32 x64 Light 保留二级页懒加载、实体路由、PID+创建时间与跨进程驱动租约。预先运行的驱动不由退出的 Light 误停；R3 浏览和证据在驱动不可用时继续工作。

命令框默认导航模块/实体，只有前导 ! 执行 shell。成功导出进入证据会话，可做最近两次行级 diff、JSON/TSV 与用户目录脱敏。内存历史重放成功读取的本地快照，原生编辑器未包含 Qt 主程序的汇编功能。详细进程列区分未知、预热和真实 0；I/O 速率不等同物理磁盘吞吐。

11 / UI & COMPATIBILITY

搜索、窗口控制与兼容策略

全局 UI 搜索、快照差异和主题控件统一接入主工作台。窗口输入/DWM 排序在窗口和杂项两页均可直接操作；DWM 画面顺序与原生输入顺序分开。跨 UIAccess 的 Win32k 写事务仅适配精确 win32kfull 10.0.26100.9022，回执测试不代替真实点击验收。

驱动/Launcher 的 OS build 上限已取消，仍保留最低 build 16299 与逐功能能力/偏移/布局检查。解除启动上限不增加未知系统的已验证 profile，也不保证所有功能可用。

12 / EVIDENCE

沿证据阅读功能

实现/构建/签名/加载/GUI/硬件场景分别报告。API 真实自有进程与 offscreen 回归、调试器受控 VM、AMD 短时常驻和模拟注销各有不同范围；旧候选与新源码不能混用。未知、Partial、Truncated、丢事件、候选和 NOT_RUN 都保留在结论中。

13 / OPERATOR NOTES

使用顺序

  1. 1
    选择配套构建并先查看状态。

    记录系统、驱动、profile、目标身份与能力；Unsupported 和缺数据不能读成“没有异常”。

  2. 2
    先观察与导出，再做修改。

    内存/文件暂存不等于已写入；注销/删除/HVM 操作保留确认和恢复记录。

  3. 3
    检查实际结果与覆盖范围。

    核对回读、路径存在、后置枚举、完整 CPU 集合和丢失统计；失败或部分完成不报告整体成功。
