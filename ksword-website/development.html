版本与下载

完整版用 Qt6，界面和功能最完整。Light 用原生 Win32，绕过 Qt6 的兼容范围，启动更快。CLI 用于脚本和批量操作，MCP 让 AI 客户端直接接入主程序或 CLI。

下载文档MCP

CLI / MCP

AI 客户端可以读取表格和控件、切换页面、执行操作，也能调用 KswordCLI。批量查询和导出可以写成脚本。“设置 → MCP”里可以启停服务、复制客户端配置和查看日志。修改类命令会要求确认。

进程 Cross-View 与结构详情

交叉核对进程链表、CID 和线程来源，找只在某个来源出现的对象、孤儿线程和异常入口。详情里可以查模块、句柄、令牌、PEB，以及 PDB 中的字段偏移、类型和位域。权限页还能比较令牌、组成员和 LSA 权限。

注册表编辑

可以同时开多个注册表标签，编辑键值、打开注册表文档。修改前先看差异，应用后读回结果；CLI 和 Light 也能做常用查询。

CKS 管理

查看 CKS 状态，按官方流程登记，或使用 SSDE 实验流程。“免重置研究”里放的是研究记录，目前还没有验证成功的免重置启用方案。

HVM / DMA Cross-View 与内存编辑

同一段内存可以走 R3、R0、HVM 私有页表和 DDMA，逐页、多轮比较读取结果。HVM 不走常规内存管理函数，用来排查读取 Hook；DDMA 通过磁盘控制器读取物理页，用来排查 EPT/SLAT 重定向。DDMA 需要先配置通道和暂存扇区。内存编辑支持 Hex、x86/x64 反汇编与汇编、暂存修改、撤销和差异比较，区域列表还能导出 R3/R0 dump。

API、ETW 与 Syscall 跟踪

API Monitor 按目标进程的位数加载 Agent，记录参数、返回值和调用栈。ETW、Syscall、WMI 和内核回调都有对应的监控页，可以按目标和事件筛选，再导出记录。

文件占用与磁盘分析

占用查询会区分句柄和映射，帮你找到占用文件的进程。文件页支持属性、哈希、签名、字符串和 Hex 检查；更底层的操作有 R0 文件工具、原始磁盘和文件系统分析。

内核回调、Hook 与对象

查看驱动、设备栈、SSDT、IDT 和内核对象，定位回调和函数指针属于哪个模块。回调清单覆盖进程、线程、镜像、注册表、Ob、Minifilter 等类型。PDB/DynData 用来解析不同系统版本的结构和偏移，内核知识页可以直接跳到对应工具。

EPT、影子页与 R-1

Intel VT-x / EPT 支持原始视图与执行视图、影子页、Hook 和执行断点。可以直接用 R-1 内存工具，也可以接 CE / x64dbg。AMD SVM / NPT 和嵌套 SVM 还在实验阶段，能否启动以硬件检测结果为准。

嵌套虚拟化

拓扑演示可以看到 Intel 嵌套虚拟化中主机、虚拟机和 KSword 分别在哪一层。具体支持哪些组合、怎么配置、哪些已经测过，见虚拟化文档。

R-1 内存工具

虚拟化启动后，可以读取物理或虚拟内存、翻译地址、定位目标进程。页面会列出当前后端支持的读取、写入和目标操作。

CE / x64dbg 与剪贴板保护

CE 和 x64dbg 保留自己的界面，通过插件接入 KSword 的 R0/R-1 内存和调试后端，支持 EPT/Shadow 执行断点。剪贴板保护可以按进程或全局规则记录、放行或阻止访问。

Light 轻量版

原生 Win32 界面，不依赖 Qt6，启动快，也绕过了 Qt6 的系统兼容范围。能查进程详情，在进程、文件、网络、句柄和窗口之间跳转，比对快照，导出 JSON/TSV。需要最完整的界面和插件功能时用完整版。

窗口、网络与页面搜索

窗口检查可以看 Win32 和 UIA 两棵控件树；网络页可以查连接、找端口占用和抓包。页面太多时，直接用标题栏搜索，或在 Taskbar 总览里按名称、路径跳转。

快照比较与导出

表格可以保存快照，对照前后哪些行、哪些字段变了。报告里的搜索、复制和导出包含完整数据；内存编辑器也能保留读取快照，对比字节变化。
