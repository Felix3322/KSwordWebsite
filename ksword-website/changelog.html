2026-10-05 / UPDATE

源码更新

开发版
  • 内存编辑器支持 x86/x64 Intel 汇编、暂存修改、撤销/重做和字节差异。写入后重新读取目标内存，核对实际结果。
  • API Monitor 收录 641 项 API 定义，分别提供 x86/x64 Agent；主程序可跨位数注入，并显示 Hook 覆盖情况与异步 I/O 关联。修正 ETW 进程身份、事件布局和 Syscall 记录。
  • 文件工具增加元数据修改与备份、签名摘要、全文件字符串搜索，以及从偏移跳到 Hex；R0 删除按阶段返回结果。
  • EX 回调注销前核对所选行身份，并调用对应公开 API；Minifilter 通过卸载所属过滤器移除。新增回调事件监控和 71 个内核知识专题。
  • CE/Titan 调试器共用后端，EPT/Shadow 执行路径按策略选择。补充剪贴板保护会话，以及 Light 的对象跳转与调查记录。
  • 加入 Intel 嵌套虚拟化与页租约实现、AMD SVM/NPT 实验代码。ENFORCE 仍返回 UNIMPLEMENTED，AMD 运行完整 L2 系统尚未验收。
  • 移除 OS build 上限，保留最低版本检查；各项功能仍按当前系统和驱动能力检查后开放。

2026-08-27

KswordARK 5.1.4.3Pre

5.1.4.3Pre

更新内容

  • 新增内核知识中心：12 类、71 个专题，可全文搜索、查看官方参考，并查询 R3/R0 现场数据或跳到对应只读页面。
  • 新增内核回调监控，可实时采集进程、线程、镜像、注册表、对象和文件回调事件，支持过滤、暂停和丢失统计；CLI 增加对应查询与启停命令。
  • HVM 增加 Intel VT-x/EPT 常驻监控，并检查电源状态、处理器拓扑和 VMX 状态；常驻时阻止卸载驱动。此 tag 不允许在 AMD、已有 Hypervisor 或检查未通过时启动，后续变化见上方开发版记录。
  • 进程详情新增单核 CPU 利用率归因、可展开图表、线程 CPU 亲和性、性能历史快照和表格快照比较；启动项支持多选。
  • Light 将性能和总线工具放入硬件页，网络、窗口工具各归主功能页；补齐进程字段与详情，改用差量刷新，修复退出时的驱动卸载。
  • 蓝屏诊断按 Stop Code、关键进程和候选模块组织。改为手动“本次安装”或设置自动安装；普通驱动加载默认不再扫描 BGP 私有路径或注册诊断回调。
  • 详情和报告页改为分组字段；标题栏搜索可按范围筛选。修复组合框弹层重入崩溃及高频刷新问题。
  • 修复 SYSTEM/提权重启与单实例检查的冲突；启动项边枚举边显示。标准发行包移除实验性存储控制器驱动及其界面。
