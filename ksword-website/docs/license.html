当前许可证

当前版本为 KSword Community Source License v1.6，自 2026-08-16 生效。下面列出主要要求，完整条款见 LICENSE。

阅读完整 LICENSE ↗

你可以做什么

  • 查看、运行、研究和修改受该许可证覆盖的 KSword 自有代码。
  • 在遵守条件的前提下免费分发原版或修改版，并对安装、配置、培训、定制和技术支持收取真实服务费用。
  • 在满足许可证第 6 条条件时提供托管服务或 SaaS；许可证允许商业使用，但不允许把软件本身作为商品出售。

分发时需要注意

  • 保留完整许可证、版权、来源信息和官方仓库地址。
  • 对外分发或通过在线服务提供修改版时，提供与实际版本对应的完整源码，并在最后一次分发或服务后至少保持三年可访问。
  • 醒目标明修改版并非 KSword 官方版本，披露实质性修改、版本来源、修改日期和源码地址。

第三方代码与插件

Qt、ADS、System Informer DynData 以及其他第三方组件保留各自许可证。插件也可能使用独立许可证；KSword 自有代码的许可证不能替代插件目录、上游项目或二进制包中的许可文件。

发行包中的 LICENSE

发行包的 Release 目录中应有 LICENSE。主程序顶部的“许可证”页读取的就是这个文件。分发时请带上它；包里缺少时，可向 GitHub Issues 报告打包问题。
