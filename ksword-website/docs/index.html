选择工作模式

进程、文件和网络的基础查询可从 R3 开始。需要内核信息时再连接 R0 驱动；页面会显示功能是否可用。

安装与启动

完整解压发行包，保留程序旁的 Qt 依赖、profiles、languages 和插件目录，运行 Launcher.exe 选择入口。

详细说明 →

连接驱动

打开驱动管理，选择配套驱动并启动。连接后查看状态与功能列表；加载失败时先检查管理员权限、签名和系统配置。

符号与动态偏移

使用与当前系统模块匹配的 PDB/DynData 配置。缺少配置时，可通过 Launcher 收集报告并提交兼容性信息。

连接调试器

安装匹配的 Cheat Engine 或 x64dbg/x96dbg 插件，在 KSword 中选择后端，再从调试器连接目标。调试器使用自己的窗口，控制与日志保留在 KSword。

详细说明 →

查看进程

从进程列表打开详情，按线程、模块、句柄、令牌和内存分类查看。操作前确认进程路径与实例，常用操作位于右键菜单。

内存编辑与区域导出

读取快照后切换 Hex、反汇编或文本视图。编辑先进入暂存区，确认差异后写回。区域列表右键可导出 R3/R0 dump；部分读取会报错，取消或失败会清理未完成文件。

详细说明 → 入口、保存语义与验证 →

文件管理与占用查询

在双面板中浏览文件，右键查看属性、计算哈希或查询占用。根据结果定位相关进程，再选择合适的解锁方式。

内核工具

连接驱动后查看驱动、设备、回调和内核对象。使用详情、符号和知识中心解释字段；修改类操作请先保存当前结果。

连接与端口

从连接列表定位进程，使用端口诊断查找占用来源。抓包工具提供接口选择、过滤与导出；修改连接或限速设置前确认目标。

安装插件

从插件市场或本地目录安装插件，重新加载后从对应页面打开。调试器类插件还需要安装其宿主程序。

注册表与系统设置

注册表支持键值编辑、文档视图和变更预览。应用修改后检查返回结果；调整启动项、服务或原始磁盘前保留原配置与备份。

注册表功能与边界 → 注册表 CLI 命令 →

结束会话

停止当前监控和调试任务，再关闭工作区。虚拟化常驻和驱动操作请使用各自页面的停止与卸载入口。

遇到问题

保留错误提示、系统版本、程序版本和相关日志。先检查页面状态和依赖，再通过 GitHub Issues 提交可复现的问题。

提交 GitHub Issue ↗

启动监控

选择目标和事件类型，启动 ETW、Syscall 或 WinAPI 会话。使用过滤与暂停阅读事件，结束后导出需要的记录。

详细说明 →

虚拟化工具

在 KVM 页面查看硬件与环境检测，按步骤准备、启动和停止。AMD 相关功能仍属实验阶段，详细配置见虚拟化文档。

详细说明 →

使用 Light

Light 提供原生 Win32 查询界面、实体导航和快照比较。查询后可导出 JSON/TSV；功能和插件范围与完整版不同。

详细说明 →

剪贴板保护

按进程或全局设置读取、写入和枚举规则。启动保护后查看 Agent 状态与日志，再按需要调整允许、记录或阻止策略。

详细说明 →

系统要求

完整版使用 Windows 10 1809（build 17763）或更新的 x64 系统。R0 功能另受驱动签名、系统配置和动态偏移支持影响。

详细说明 →

接入 MCP

打开“设置 → MCP”，复制安装提示词或客户端配置。安装时选择 GUI、CLI 或两者，并设置未运行时的启动方式；管理员启动由 Windows UAC 确认。

MCP 工具与配置 → 安装与分层验收 →

使用命令行

运行 KswordCLI help 查看命令，也可在文档中心按进程、文件、注册表等分类查找。MCP 可调用 CLI；原始 IOCTL 请求需要明确确认，输入和输出各限 1 MiB。

CLI 总手册 → R3 覆盖清单 → IOCTL 语法与限制 →

报告与权限工作台

在进程详情中展开结构报告，搜索字段并复制或导出。权限工作台可查看账号、组成员和令牌，比较快照并诊断访问权限。

报告行为与验收 → 权限工作台 →

查找页面

使用标题栏搜索页面和控件，或从 Taskbar 右侧网格按钮打开页面总览。输入名称或路径后按 Enter 跳转，Esc 收起总览。

页面搜索、启动与 SOS →

CKS 管理

从“杂项 → CKS 管理”查看状态和登记流程。第三个子页收录免重置研究，目前两条候选均未验证成功。
